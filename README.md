# Transceiver CHIRP Library

Repository for CHIRP radio configurations, drivers, and setup scripts.

## Layout

- `chirp/packages/` for CHIRP installers and wheels.
- `chirp/drivers/` for custom CHIRP driver files.
- `configs/` for radio-specific CHIRP backups and images.
- `scripts/` for install, export, and import helpers.

## Usage

1. Install CHIRP:

```sh
./scripts/install-chirp-native.sh
```
